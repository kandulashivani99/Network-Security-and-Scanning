\# WHOIS Reconnaissance



\## Objective

To collect publicly available domain registration information using the WHOIS lookup utility.



\## Tool

WHOIS



\## Command

```bash

whois example.com

```



\## Information Observed

\- Domain name

\- Registrar information

\- Registration and expiry dates, when available

\- Name servers

\- Registry information



\## Conclusion

WHOIS helps gather publicly available domain registration details during the passive reconnaissance phase.
