\# Nslookup – DNS Reconnaissance



\## Objective

To identify the IP address associated with a domain name using DNS lookup.



\## Tool

Nslookup



\## Commands Used

nslookup example.com

nslookup google.com



\## Information Observed

\- DNS server information

\- Domain name queried

\- IP address returned

\- DNS resolution results



\## Conclusion

Nslookup helps identify domain-to-IP address mappings and understand DNS resolution during passive reconnaissance.
