# DNS Traffic Analysis Using Wireshark

## 1. Objective

To capture and analyze DNS traffic using Wireshark and understand how domain names are resolved into IP addresses.

## 2. Tools Used

- Wireshark
- Windows PowerShell
- Windows DNS client (`nslookup`)

## 3. Practical Procedure

1. Opened Wireshark on the Windows system.
2. Selected the active network interface and started packet capture.
3. Opened PowerShell and executed:

   ```powershell
   nslookup example.com
   ```

4. Generated DNS queries to resolve the domain name.
5. Returned to Wireshark and applied the display filter:

   ```text
   dns
   ```

6. Examined the captured DNS packets.

## 4. Observations

The DNS filter displayed packets related to domain name resolution.

The captured traffic helped demonstrate:

- DNS queries generated by the system.
- DNS responses received from the configured DNS resolver.
- Domain name resolution for `example.com`.
- Communication between the client system and DNS resolver.

DNS commonly uses UDP port 53, although TCP port 53 is also used in certain situations.

## 5. Result

DNS traffic was successfully generated and observed using Wireshark. The practical demonstrated how DNS translates human-readable domain names into IP addresses.

## 6. Conclusion

This experiment provided practical experience in capturing and analyzing DNS traffic. Wireshark's DNS display filter helped identify domain resolution activity and understand the role of DNS in network communication.
